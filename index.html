C++ Console Application

Flame Crest Arena

A turn-based C++ battle game inspired by Fire Emblem. The player selects a hero, fights increasingly difficult opponents, chooses weapons between rounds, and uses Health Potions to recover HP.

Key Features

  • Turn-based combat with hit chances, missed attacks, and critical hits.
  • Weapon stats and a Sword, Axe, and Lance weapon triangle.
  • Hero-specific weapon choices, Health Potions, and post-battle character swapping.
  • Win-streak enemy scaling that resets after the player loses.

What I Learned

Instead of writing all the code in one file, I learned how to separate a program into focused files such as Battle.cpp, Unit.cpp, WeaponData.cpp, and ItemData.cpp. I also practiced using classes, vectors, functions, loops, and conditional statements to manage game state and player choices.
